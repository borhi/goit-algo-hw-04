# Завдання 3 - порівняння сортування вставками, злиттям і Timsort

Час cортування вставками вимірюється лише для `n ≤ 8000`, для більших `n` у колонці Insert виводиться `-`, бо квадратичний алгоритм на десятках тисяч елементів став би непрактичним за часом.

Приклад виводу:

| **n** | **Insert** (ms) | **Merge** (ms) | **Timsort** (ms) |
|------:|---------------:|---------------:|-----------------:|
| 8 000 | 1250.76 | 15.91 | 0.45 |
| 30 000 | — | 67.23 | 2.86 |
| 80 000 | — | 201.48 | 7.17 |

## Висновки

Для сортування великих списків у Python доцільно користуватися `sorted` або `sort`, а Сортування вставками / злиттям залишати для навчання, дуже малих `n` або специфічних обмежень. Порівняння в `task_3.py` наглядно показує, чому «ручний» merge на Python не конкурує за швидкістю з вбудованим Timsort на великих масивах.
